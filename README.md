## 👨‍💻 Sobre mí

Soy **egresado de Ingeniería en Informática** del Instituto Profesional Santo Tomás, con experiencia práctica en **desarrollo de software empresarial, backend, integración de datos y automatización de procesos**.

Durante mi práctica profesional en **Glasstech S.A. (2026)** trabajé en soluciones para una intranet corporativa, integración con sistemas ERP y flujos de datos de producción. Esta experiencia complementa mis proyectos personales full-stack, donde he desarrollado aplicaciones con autenticación, bases de datos, APIs y despliegue cloud.

Me interesa construir software que no solo funcione, sino que sea **mantenible, seguro y útil para resolver problemas reales del negocio**.

- 💻 **Desarrollo:** C#, .NET 8, ASP.NET Core MVC, JavaScript, TypeScript, React y NestJS.
- 🗃️ **Datos:** SQL Server, PostgreSQL, MongoDB, modelado relacional y consultas SQL.
- 🔄 **Integración y automatización:** APIs REST, ETL, n8n y procesos de reportería.
- ☁️ **Infraestructura:** Docker, Git, GitHub Actions, Render, Neon y Vercel.
- 🔐 **Seguridad:** autenticación, autorización, JWT, ASP.NET Core Identity y buenas prácticas de manejo de credenciales.

## 🚀 Z Labs · Mi portafolio personal

**Z Labs** es mi identidad personal de desarrollo de software. Reúne proyectos con los que exploro arquitectura backend, experiencia de usuario, seguridad, integración de servicios y despliegue de aplicaciones reales.

### 🛒 Z-Commerce · Plataforma e-commerce full-stack

**ASP.NET Core MVC · C# · PostgreSQL · Entity Framework Core · Identity · Docker**

Plataforma de comercio electrónico con catálogo de productos, carrito, checkout, historial de compras y panel administrativo. Incluye control de acceso por roles, confirmación y recuperación de cuentas por correo, integración de **Transbank Webpay Plus en sandbox** y despliegue en la nube.

**Aspectos técnicos:** ASP.NET Core Identity, roles `Admin`, `DemoAdmin` y `Cliente`, PostgreSQL en Neon, Docker, Render, Brevo API y configuración mediante variables de entorno.

🌐 **[Ver demo](https://z-commerce-dh8r.onrender.com/)** · 📦 **[Repositorio](https://github.com/SebastianASR/Z-Commerce)**

### 🎫 Z-Entik · Sistema HelpDesk TI

**React · TypeScript · NestJS · PostgreSQL · Prisma · JWT**

Sistema de tickets para centralizar solicitudes de soporte, usuarios, técnicos, roles, estados, prioridades y comentarios. Utiliza una **arquitectura desacoplada**, con frontend React y una API REST en NestJS.

**Aspectos técnicos:** autenticación JWT, hashing seguro de contraseñas, recuperación de acceso y 2FA por correo, integración con Brevo API y tecnologías cloud y CI/CD como Docker, Render, Neon y GitHub Actions.

🌐 **[Ver demo](https://z-entik-web.onrender.com/)** · 📦 **[Repositorio](https://github.com/SebastianASR/Z-Entik)**

### 🚇 Red Metro Guía · Visualización de rutas

**React · TypeScript · Vite · Tailwind CSS · Recharts**

Aplicación web para orientar rutas y combinaciones del Metro de Santiago, con componentes reutilizables, visualización de resultados, diseño adaptable y despliegue en Vercel.

🌐 **[Ver proyecto](https://red-metro-guia.vercel.app/)**
